# ASBOB. — asbob-uskunalar ijarasi namunasi

Next.js App Router, TypeScript va Tailwind asosidagi namuna ijara so‘rovi sayti. Olti asbob bitta typed ma’lumot manbasida saqlanadi. So‘rovlar faqat tashrif buyuruvchining brauzeridagi `localStorage`da saqlanadi; haqiqiy buyurtma yoki to‘lov amalga oshirilmaydi.

GSAP sahifa kirishi, katalog belgisi va narx o‘zgarishiga yengil harakat qo‘shadi. Qisqa ochilish animatsiyasi har bir brauzer tabida bir marta ko‘rsatiladi; uni qayta ko‘rish uchun saytni yangi tabda oching. Kamaytirilgan harakat sozlamasida animatsiyalar o‘tkazib yuboriladi.

## Ishga tushirish

```bash
npm install
npm run dev
```

Brauzerda `http://localhost:3000` manzilini oching.

## Tekshiruv

```bash
npm run lint
npm run check:logic
npm run build
```
