# ASBOB. — asbob-uskunalar ijarasi namunasi

Next.js App Router, TypeScript va Tailwind asosidagi namuna ijara so‘rovi sayti. Olti asbob bitta typed ma’lumot manbasida saqlanadi. So‘rovlar faqat tashrif buyuruvchining brauzeridagi `localStorage`da saqlanadi; haqiqiy buyurtma yoki to‘lov amalga oshirilmaydi.

GSAP sahifa kirishi, katalog belgisi va narx o‘zgarishiga yengil harakat qo‘shadi. Ochilish animatsiyasi sayt har safar to‘liq yuklanganda, jumladan sahifa yangilanganda ko‘rsatiladi. Kamaytirilgan harakat sozlamasida animatsiyalar o‘tkazib yuboriladi.

## Ishga tushirish

```bash
npm install
npm run dev
```

Brauzerda `http://localhost:3000` manzilini oching.

## Tekshiruv

```bash
npm run lint
npm run check:logic
npm run build
```
